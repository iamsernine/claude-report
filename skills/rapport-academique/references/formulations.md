# Phrase bank

Standard formulas for the joints of a report. Using them is not a stylistic
failing; these are the conventions the genre expects, and inventing your own
transitions usually reads worse.

**The functions are identical in every language — only the wording changes.**
Each section below names a function, then gives French and English forms. Pick
the function first, then the column matching `lang:` in `report.yaml`. Never mix
the two columns in one report.

Vary them. Do not open all six chapters with the same sentence.

## Opening a chapter

**fr**
- Ce chapitre a pour objectif de …
- Ce chapitre vise à situer le projet dans son contexte organisationnel et technique.
- Après avoir présenté …, nous abordons dans ce chapitre …
- Le présent chapitre est consacré à …
- Nous présentons dans ce qui suit …

**en**
- This chapter sets out to …
- This chapter situates the project in its organisational and technical context.
- Having presented …, we now turn to …
- The present chapter is devoted to …
- The following sections present …

## Closing a chapter and handing off

**fr**
- Ce chapitre a permis de … Le chapitre suivant sera consacré à …
- Ces éléments étant posés, nous pouvons désormais aborder la phase de conception, objet du chapitre suivant.
- La spécification détaillée présentée ici constitue le point de départ de la conception, développée au chapitre suivant.
- Cette analyse met en évidence …, ce qui motive les choix techniques présentés dans le chapitre qui suit.

**en**
- This chapter has established … The next chapter turns to …
- With these elements in place, we can move to the design phase, the subject of the following chapter.
- The detailed specification presented here is the starting point for the design developed in the next chapter.
- This analysis highlights …, which motivates the technical choices presented in the chapter that follows.

## Stating the problem

**fr**
- Le problème se pose dans les termes suivants : …
- Cette situation soulève la question suivante : …
- La difficulté réside dans le fait que …
- Il apparaît dès lors nécessaire de …

**en**
- The problem can be stated as follows: …
- This situation raises the following question: …
- The difficulty lies in the fact that …
- It therefore becomes necessary to …

## Justifying a choice

**fr**
- Notre choix s'est porté sur … pour les raisons suivantes : …
- Cette solution a été retenue en raison de …
- Compte tenu de la contrainte de …, nous avons privilégié …
- À l'inverse de …, cette approche permet de …
- Ce choix se justifie par le compromis qu'il offre entre … et …

**en**
- We selected … for the following reasons: …
- This solution was retained because of …
- Given the constraint of …, we favoured …
- Unlike …, this approach makes it possible to …
- This choice is justified by the trade-off it offers between … and …

## Introducing a figure or table

**fr**
- La figure X illustre …
- Le tableau X récapitule …
- La figure X présente une vue d'ensemble de …
- Comme le montre la figure X, …

**en**
- Figure X illustrates …
- Table X summarises …
- Figure X gives an overview of …
- As Figure X shows, …

*(Never "la figure ci-dessous" / "the figure below" — always reference by
number. Position shifts on repagination; the number does not.)*

## Presenting results

**fr**
- Les résultats obtenus sont consignés dans le tableau X.
- Le modèle atteint une valeur de … sur le jeu de test.
- On observe une amélioration de … points par rapport à la référence.
- Ces résultats sont à mettre en regard de …

**en**
- The results obtained are reported in Table X.
- The model reaches … on the test set.
- We observe an improvement of … points over the baseline.
- These results should be read against …

## Interpreting, including unexpected results

**fr**
- Ce résultat s'explique vraisemblablement par …
- Contrairement à ce qui était attendu, …
- Cet écart peut être attribué à …
- Ce comportement mérite d'être souligné : …

**en**
- This result is most likely explained by …
- Contrary to expectation, …
- This gap may be attributed to …
- This behaviour is worth highlighting: …

## Acknowledging a limitation

**fr**
- Il convient toutefois de noter que …
- Ce résultat doit être nuancé par le fait que …
- La principale limite de cette approche tient à …
- Ces performances ne sauraient être généralisées à … sans validation complémentaire.

**en**
- It should be noted, however, that …
- This result must be qualified by the fact that …
- The main limitation of this approach lies in …
- These results cannot be generalised to … without further validation.

## Perspectives

**fr**
- Plusieurs pistes d'amélioration peuvent être envisagées : …
- Une extension naturelle de ce travail consisterait à …
- Il serait pertinent d'évaluer …
- Ce travail ouvre la voie à …

**en**
- Several avenues for improvement can be envisaged: …
- A natural extension of this work would be to …
- It would be worth evaluating …
- This work opens the way to …

## Difficulties

**fr**
- La principale difficulté rencontrée a concerné …
- Cette étape a nécessité plusieurs itérations avant d'aboutir à …
- Nous avons dû revoir … à la suite de …

**en**
- The main difficulty encountered concerned …
- This step required several iterations before arriving at …
- We had to revise … following …

## General conclusion

**fr**
- Ce travail avait pour objectif de … Les résultats obtenus montrent que …
- Au terme de ce projet, …
- Sur le plan personnel, ce stage m'a permis de …

**en**
- This work set out to … The results obtained show that …
- At the close of this project, …
- On a personal level, this placement allowed me to …

## Formulations to avoid

The failure mode is the same in both languages; only the example changes.

| Avoid (fr) | Avoid (en) | Why | Use instead |
|---|---|---|---|
| "Comme on peut le voir ci-dessous" | "As can be seen below" | Breaks on repagination | Reference by number: "La figure 3.2 montre…" / "Figure 3.2 shows…" |
| "Il est évident que…" | "It is obvious that…" | Asserts rather than argues | "Les résultats indiquent que…" / "The results indicate that…" |
| "Notre solution révolutionne…" | "Our solution revolutionises…" | Overclaiming; juries react badly | "Notre approche permet de…" / "Our approach makes it possible to…" |
| "Le système est très performant" | "The system is very fast" | Unmeasurable | Give the number |
| "Etc." in a technical list | "etc." in a technical list | Reads as an unfinished sentence | Complete the list, or "notamment" / "in particular" |
| First person singular in a group report | Same | Inconsistent voice | Choose "nous" / "we" and hold it throughout |
