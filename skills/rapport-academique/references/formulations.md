# Phrase bank — academic French

Standard formulas for the joints of a report. Using them is not a stylistic
failing; these are the conventions the genre expects, and inventing your own
transitions usually reads worse.

Vary them. Do not open all six chapters with the same sentence.

## Opening a chapter

- Ce chapitre a pour objectif de …
- Ce chapitre vise à situer le projet dans son contexte organisationnel et technique.
- Après avoir présenté …, nous abordons dans ce chapitre …
- Le présent chapitre est consacré à …
- Nous présentons dans ce qui suit …

## Closing a chapter and handing off

- Ce chapitre a permis de … Le chapitre suivant sera consacré à …
- Ces éléments étant posés, nous pouvons désormais aborder la phase de conception, objet du chapitre suivant.
- La spécification détaillée présentée ici constitue le point de départ de la conception, développée au chapitre suivant.
- Cette analyse met en évidence …, ce qui motive les choix techniques présentés dans le chapitre qui suit.

## Stating the problem

- Le problème se pose dans les termes suivants : …
- Cette situation soulève la question suivante : …
- La difficulté réside dans le fait que …
- Il apparaît dès lors nécessaire de …

## Justifying a choice

- Notre choix s'est porté sur … pour les raisons suivantes : …
- Cette solution a été retenue en raison de …
- Compte tenu de la contrainte de …, nous avons privilégié …
- À l'inverse de …, cette approche permet de …
- Ce choix se justifie par le compromis qu'il offre entre … et …

## Introducing a figure or table

- La figure X illustre …
- Le tableau X récapitule …
- La figure X présente une vue d'ensemble de …
- Comme le montre la figure X, …

*(Never "la figure ci-dessous" or "le tableau suivant" — always reference by number.)*

## Presenting results

- Les résultats obtenus sont consignés dans le tableau X.
- Le modèle atteint une valeur de … sur le jeu de test.
- On observe une amélioration de … points par rapport à la référence.
- Ces résultats sont à mettre en regard de …

## Interpreting, including unexpected results

- Ce résultat s'explique vraisemblablement par …
- Contrairement à ce qui était attendu, …
- Cet écart peut être attribué à …
- Ce comportement mérite d'être souligné : …

## Acknowledging a limitation

- Il convient toutefois de noter que …
- Ce résultat doit être nuancé par le fait que …
- La principale limite de cette approche tient à …
- Ces performances ne sauraient être généralisées à … sans validation complémentaire.

## Perspectives

- Plusieurs pistes d'amélioration peuvent être envisagées : …
- Une extension naturelle de ce travail consisterait à …
- Il serait pertinent d'évaluer …
- Ce travail ouvre la voie à …

## Difficulties

- La principale difficulté rencontrée a concerné …
- Cette étape a nécessité plusieurs itérations avant d'aboutir à …
- Nous avons dû revoir … à la suite de …

## Conclusion générale

- Ce travail avait pour objectif de … Les résultats obtenus montrent que …
- Au terme de ce projet, …
- Sur le plan personnel, ce stage m'a permis de …

## Formulations to avoid

| Avoid | Why | Use instead |
|---|---|---|
| "Comme on peut le voir ci-dessous" | Breaks on repagination | "La figure 3.2 montre…" |
| "Il est évident que…" | Asserts rather than argues | "Les résultats indiquent que…" |
| "Notre solution révolutionne…" | Overclaiming; juries react badly | "Notre approche permet de…" |
| "Le système est très performant" | Unmeasurable | Give the number |
| "Etc." in a technical list | Reads as an unfinished sentence | Complete the list or say "notamment" |
| First person singular in a group report | Inconsistent voice | Choose "nous" and hold it throughout |
