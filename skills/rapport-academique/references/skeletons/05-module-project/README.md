# 05 — Module project / mini-projet / TP long

**Use this when:** the report accompanies a course project — no company, no
formal jury, graded by the module's instructor. 12–25 pages.

There is no organisme d'accueil, so delete every reflex that comes with it. No
company presentation, no organigramme, no internship framing. Starting a
mini-projet report with three pages about a company you did not work at is the
fastest way to look like you copied a template.

## Shape

Three chapters, 12–25 pages.

| Chapter | Answers |
|---|---|
| 1. Étude préalable | What is the problem and what already exists? |
| 2. Conception | What is the design? |
| 3. Réalisation | What was built and does it work? |

## What the instructor is actually grading

- Did you understand the requirement, or did you build something adjacent to it?
- Is the design justified, or arbitrary?
- Does it run? Is there evidence it runs?
- Can someone else set it up from your README?

That last point is worth more than it looks. Include the setup instructions in an
annex or in the repository, and say so.
