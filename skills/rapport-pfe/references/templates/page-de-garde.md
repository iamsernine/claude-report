Text centred. No abbreviations in the title. No page number on this page.

```
                    ROYAUME DU MAROC
        [Université] — [École / Faculté]
                      [logo]                    [logo entreprise]

              Département [nom du département]
                  Filière [nom de la filière]

        ─────────────────────────────────────────

              PROJET DE FIN D'ÉTUDES
        Pour l'obtention du titre d'Ingénieur d'État

        ─────────────────────────────────────────

                    [TITRE DU PROJET]
                    (spécifique, sans abréviation)

        ─────────────────────────────────────────

        Réalisé par :               Encadré par :
        [Prénom NOM]                Pr. [Prénom NOM]  — encadrant académique
                                    M. [Prénom NOM]   — encadrant entreprise

        Soutenu le [date] devant le jury composé de :

        Pr. [Prénom NOM]   — Président
        Pr. [Prénom NOM]   — Examinateur
        Pr. [Prénom NOM]   — Encadrant

                  Année universitaire 20XX–20XX
```

## Notes

- The title is the most-read part of the report after the abstract. It must give
  the best possible view of the work in the fewest words, and it must be
  specific. Never use an abbreviation in it.
- Adjust the degree line to the document: *Projet de Fin d'Année*, *Rapport de
  projet de module*, *Mémoire de Master*.
- For a module project, drop the jury block and name the module and instructor
  instead.

## Résumé template

```
Résumé

[Objective — 1–2 sentences.]
[Problem and methodology — 2–3 sentences.]
[Main results, with numbers — 2–3 sentences.]
[Conclusion and contribution — 1–2 sentences.]

Mots-clés : [terme 1], [terme 2], [terme 3], [terme 4], [terme 5]
```

Then the same again in English as `Abstract` / `Keywords`. 150–250 words each.
Write both last.
