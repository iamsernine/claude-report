# Outline — module project

Target 12–25 pages. If you are past 25, you are writing the wrong document.

---

## Front matter

- Page de garde — institution, filière, module, project title, authors,
  instructor, academic year
- Sommaire
- Liste des figures — only if there are several

*(No dédicaces. Remerciements optional and short.)*

## Introduction — half a page to one page

Context, problem, objectives, plan.

---

## Chapitre 1 — Étude préalable

### 1.1 Présentation du problème
### 1.2 Étude de l'existant
- Comparable tools or approaches, and their limits
- A small comparison table works well here

### 1.3 Spécification des besoins
- Functional requirements, numbered
- Non-functional requirements, short

### 1.4 Choix méthodologique
- Working method and planning, in a paragraph

---

## Chapitre 2 — Conception

### 2.1 Architecture générale
- One diagram

### 2.2 Modélisation
- Use case diagram, class diagram, or the pipeline diagram — whichever the
  project actually calls for. Do not include diagrams because a template listed
  them.

### 2.3 Modèle de données
- If there is persistence

### 2.4 Maquettes
- If there is a UI

---

## Chapitre 3 — Réalisation

### 3.1 Environnement de travail et technologies
- Stack with versions, and a one-line justification each

### 3.2 Implémentation
- The interesting parts. Include a short code excerpt only where it illustrates a
  design decision — never as filler.

### 3.3 Présentation du résultat
- Readable screenshots, or output samples

### 3.4 Tests
- A test table: case, expected, obtained, verdict

---

## Conclusion et perspectives — half a page

What was achieved, what was not, what you would do next.

---

## Back matter

- Bibliographie / Webographie
- Annexe A — installation and execution instructions
- Annexe B — repository link, if the code is hosted
